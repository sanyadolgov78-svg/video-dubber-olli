# Озвучка видео на французский — техническая документация

Локальный конвейер: `input/*.mp4` → транскрибация → перевод → полишинг → озвучка → `output/*_fr.mp4`.

Всё считается на своей машине, без облачных сервисов. Нужен ffmpeg в `PATH`.

## Установка

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements-full.txt
cp config.example.json config.json    # заполнить пути к моделям
```

Модели и голоса кладутся в каталог без не-ASCII символов (кириллицы): sentencepiece и Piper не открывают такие пути. Каталог задаётся переменной `SKIT_MODELS_DIR`, по умолчанию `C:\skit_models` на Windows и `~/skit_models` на Linux.

## Запуск

```bash
python run_pipeline.py                      # разовый прогон
python run_pipeline.py --watch --interval 5 # авторежим: следит за input/
```

Авторежим и надзор за ним — `watchdog.py`, он поднимает сторож, если тот упал.

## Поток этапов

Конвейец останавливается на каждом шаге, чтобы человек проверил текст:

1. нет `<имя>.srt` → транскрибация → **стоп**, проверить русский текст
2. русский SRT не редактировался → **стоп**
3. русский SRT отредактирован → перевод → **стоп**, проверить перевод
4. перевод не редактировался → **стоп**
5. иначе: полишинг → проверка чувствительного контента → озвучка → экспорт

Сброс этапа: удалить `.srt.orig` — переозвучка без правок; удалить `_{lang}.srt` — новый перевод; удалить `.srt` — заново распознать.

## Субтитры

Собираются в `pipeline/export.py`, вшиваются ffmpeg-фильтром `subtitles` с `force_style`.

- **Ключ размера шрифта — `FontSize`.** `AppFontSize` libass игнорирует: текст молча рисуется дефолтным шрифтом ASS, и настройки кегля выглядят неработающими.
- **Растягивать текст пробелами нельзя.** Строка наполняется реальными словами, длины выравниваются разбивкой (`_balance_lines`), поля по краям симметричны.
- **Вместимость строки** считается по замеренной ширине глифа: `subtitles_char_em` (около 0.21 em/симв) и `subtitles_width_frac`. Завышенный коэффициент даёт вдвое меньше слов в строке.
- **Строк — минимум, длина — поровну**, но не больше `subtitles_portrait_max_lines`.
- **Цвета в ASS — это BGR, а не RGB.** `#ffc957` в конфиге → `PrimaryColour=&H0057C9FF` в `force_style`. Перестановка каналов даёт синий текст вместо оранжевого. Преобразование — `_ass_color()`.
- **`FontSize` пересобирается в двух ветках** (портрет и подгонка под полосу блюра). Оформление букв при каждой пересборке добавляется заново, иначе текст останется белым.
- **Позиция** (`MarginV`) считается по высоте всего блока, а не одной строки, иначе многострочный текст вылезает за полосу блюра.
- **Проверять результат надо измерением, а не на глаз:** извлечь кадр через `ffmpeg -ss T -frames:v 1` и посчитать пиксели в нижней трети кадра (для `#ffc957` ожидается `#ffc757` ±2 из-за сжатия H.264), затем распознать текст OCR.

## Озвучка

`"auto"` — по полу источника: женский → Kokoro (быстро, статичный голос), мужской/неизвестный → XTTS с клонированием. Два движка отличаются по скорости примерно в 6 раз, XTTS копирует голос спикера, Kokoro — нет.

При `clone_speaker_voice` голос вырезается из самого ролика по таймкодам, XTTS озвучивает целевой язык тембром спикера.

## Перевод и полишинг

Перевод локальный: `opus-mt-ru-fr` через `transformers`. Полишинг — локальная LLM через Ollama, посегментно, с сверкой русского оригинала; правки пишутся в тот SRT, по которому потом озвучивается. Если Ollama недоступна и `polish_required: true` — конвейер останавливается вместо озвучки непроверенного текста.

`MBART` требует `use_fast=False` и `sentencepiece==0.2.2`.

## Известные грабли

- **Мало RAM.** Модель полишинга занимает около 5 ГБ и держится после генерации. В коде сделаны выгрузки между этапами (`keep_alive: 0`, `_unload_ollama`, `unload_models()`) — не удалять их, иначе перевод и полишинг вместе дают краш 0xC0000005.
- **Два сторожа одновременно портят выходные файлы** (битые NAL, цифровая тишина). Защита — PID-лок в `work/`; если он мешает, удалить и перезапустить.
- **Ручная пересборка при живом стороже тоже портит вывод:** экспорт обрывается или падает с ошибкой «файл занят». Перед ручной пересборкой сторож остановить, после — поднять.
- **Проверять длительность результата через `ffprobe`, а не доверять «готово» в логе:** прерванный процесс успевает напечатать успех и оставить обрезанный файл.
- **Kokoro требует eSpeak-NG.** Для французского библиотека при импорте подменяет пути на свои, и `tts.py` сбрасывает их, иначе phonemizer падает или не находит язык.
- **Kokoro не клонирует голос**, и французских мужских голосов в нём нет — такие ролики уходят в XTTS.
- **XTTS распространяется по некоммерческой лицензии Coqui (CPML).**

## Кириллица в файлах

Правки файлов с не-ASCII путями — только через Python (`io.open(..., encoding="utf-8")`) или PowerShell `[System.IO.File]::WriteAllText`, UTF-8 без BOM. PowerShell 5.1 читает `.ps1` с кириллицей как ANSI, и встроенный путь к интерпретатору превращается в мусор — такие скрипты писать в ASCII либо сохранять в UTF-8 с BOM.

После правки: `python -m py_compile <файл>`.
