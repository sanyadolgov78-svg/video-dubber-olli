# Автоматическая озвучка видео на французский и английский

Локальный конвейер: берёт видео из `input/`, распознаёт речь, переводит на целевой язык, исправляет перевод через LLM, озвучивает и собирает готовое видео в `output/`.

Полностью на своей машине, без облачных сервисов и оплаты.

## Языки

Переключение — одной настройкой `target_lang`. Остальные параметры подтягиваются из пресета.

| | Французский `fr` | Английский `en` |
|---|---|---|
| Модель перевода | `opus-mt-ru-fr` | `opus-mt-ru-en` |
| Язык XTTS | `fr` | `en` |
| Движок по умолчанию | `auto` | `xtts` |
| Голоса Kokoro | `ff_siwis` (единственный) | `am_michael` / `af_heart` |

Обе модели перевода уже входят в кэш — при переключении ничего не докачивается.

**Движок озвучки.** `auto` выбирает по полу спикера: женский → Kokoro (быстро, ~1 мин на ролик), мужской → XTTS. `xtts` клонирует голос говорящего из самого ролика и медленнее (~6 мин), зато сохраняет характер голоса. `kokoro` — только статичные голоса.

**Ограничение Kokoro:** французский голос в нём один, мужского нет. Поэтому для `fr` режим `auto` уводит мужской пол в XTTS. У английского оба пола есть.

**Переключение из командной строки:**
```bash
python run_pipeline.py --lang en
python run_pipeline.py --lang fr
```

Постоянный язык задаётся в `config.json`:
```json
"target_lang": "en"
```

Файл результата называется по языку: `<имя>_fr.mp4` или `<имя>_en.mp4`.

## Как это работает

1. **Транскрибация** — `faster-whisper` распознаёт речь с таймкодами, определяет язык и пол говорящего.
2. **Перевод** — локальная модель `Helsinki-NLP/opus-mt-ru-fr` через `transformers`.
3. **Полишинг** — локальная LLM (Ollama) делает французский естественным, сверяясь с оригиналом.
4. **Озвучка** — `Kokoro-82M` (быстрые статичные голоса) или `Coqui XTTS` (клонирование голоса спикера). Движок выбирается сам по полу говорящего либо задаётся в конфиге.
5. **Экспорт** — `ffmpeg` склеивает дорожку с видео и вшивает субтитры.

Конвейец **останавливается после транскрибации и после перевода**, чтобы человек проверил текст до озвучки.

## Установка

Нужен ffmpeg в `PATH`.

```bash
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements-full.txt
cp config.example.json config.json
```

Модели и голоса складываются в каталог **без не-ASCII символов** — sentencepiece и Piper не открывают пути с кириллицей. Каталог задаётся переменной окружения `SKIT_MODELS_DIR` (по умолчанию `C:\skit_models` в Windows, `~/skit_models` в Linux). Размер моделей — около 3 ГБ, скачиваются автоматически при первом запуске.

## Использование

```bash
python run_pipeline.py                      # все видео из input/ за один проход
python run_pipeline.py --watch --interval 5 # следить за папкой и обрабатывать новое
python run_pipeline.py "путь/к/видео.mp4"   # конкретный файл
python run_pipeline.py --lang en            # сразу на английском
```

Видео кладётся в `input/`, результат появляется в `output/` как `<имя>_fr.mp4` или `<имя>_en.mp4`.

Сторож можно запускать под надзором — `watchdog.py` поднимет его сам, если процесс упадёт.

## Настройка

Все параметры — в `config.json` (создаётся из `config.example.json`). Основные:

| Ключ | Значение |
|---|---|
| `target_lang` | `fr` или `en` — язык перевода и озвучки |
| `tts_engine` | `auto` / `kokoro` / `xtts` |
| `dub_enabled` | `false` — только распознавание и перевод, без озвучки |
| `polish_enabled` / `polish_required` | полишинг перевода и строгость: `true` в `polish_required` останавливает конвейер, если LLM недоступна |
| `montage_*` | блюр чужих субтитров, логотип, интро |
| `subtitles_only_enabled` | для чувствительного контента вместо озвучки вшиваются субтитры |
| `subtitles_primary_color` и соседние `subtitles_*` | оформление букв в субтитрах |

## Проверка транскрипта

Конвейер **дважды останавливается и ждёт вас**: после распознавания и после полишинга. Пока вы не подтвердите правки, озвучка не начнётся. Формат файлов и порядок работы — в [docs/transcript-review.md](docs/transcript-review.md).
